# Reproducibility metadata archive

Captured from the research instance after commit 2fb00f3. index.json enumerates the archives. JSONL records contain the original relative path, original file SHA-256 and parsed content (or literal text for CSV). Large archives are split on complete record boundaries. Local absolute paths inside scientific metadata describe the original run; substitute your local roots when reproducing.

- environment.json and packages.txt record the current hardware, OS, Python, CUDA backend and installed distribution versions. The package list is an inventory, not a tested clean-install lockfile. It intentionally omits environment variables, authenticated URLs, host identifiers and credentials. The container image digest was not established; host driver and kernel are recorded.
- dataset_manifests.jsonl preserves official four-dataset preparation manifests, the ACDC tuning preparation, L2R-OASIS preparation and exact Tuning32 selection. Existing manifest hashes are retained; source images were not rehashed wholesale during this pass. Download manifests and signed download links are excluded.
- classical and neural_corrected archives preserve per-case run settings, metrics, summaries and plans from the two official baseline roots. The neural tree is the corrected NIR/DNVF output tree, including NIR thin-ACDC retries; superseded incorrect results are not resurrected.
- ablations and tuning archives preserve per-case settings/scores, plans, configurations and selection/ranking decisions. Historical experiments are observations, not alternative canonical defaults.
- analysis preserves case-advantage, centroid and selected analysis metadata. PNGs are under docs/media; saved recovery volumes are outside Git.
- default_run_inventory.jsonl lists every file in results/official_ours_cosine_20261116, with relative path, byte size and SHA-256. The user is backing up this whole directory separately. That download has not been independently verified here.
- upstream_audit.json records verification against baselines/sources.json. Every Git checkout matched its pinned revision plus its exact recorded patch, and no untracked source files were found. NIR and NODEO changes are fully preserved in baselines/patches; setup applies them. Other methods had no tracked upstream edits. Demons uses its pinned installed package. Runtime localization and numerical overrides live in tracked adapters/configurations, with the classification and rationale in docs/BASELINE_PROTOCOL_REVIEW.md. NiftyReg source/build setup is tracked, but compiled binaries and local build caches are excluded.

No experiments were launched to create this archive. It is metadata-only and does not replace external backups of the default run and exact prepared datasets. The roughly 36 MiB archive avoids copying weights, image arrays, maps and raw logs. Raw JSON nonfinite values, where present in original scientific records, retain Python JSON's NaN/Infinity representation; readers requiring strict JSON must handle those explicitly.
